# Fifteen-Day Frontline

A browser-based 3D/WebGL large-map battlefield survival shooter prototype.

## Play Online

After the GitHub Pages deployment, visit:

https://keng0nion.github.io/fifteen-day-frontline/

## Game Content

- Three.js/WebGL 3D battlefield
- Large-map day/night cycle and weather
- Multiple factions and squad-level tactical AI
- Gunshot investigation, flanking, suppression, airdrop contesting
- Hunting for food
- Status effects: hunger, health, bleeding, fractures, infection, suppression, and more
- Medical rules: bandages stop bleeding only, splints treat fractures only, antibiotics treat infection only, rations restore hunger only, and only transfusion kits restore health
- Death returns straight to the main menu
- Survive 15 days or complete 5 system missions to reach an ending

## Run Locally

Open `index.html` directly to play; you can also host the whole directory with any static server.

Main files:

- `index.html`
- `styles.css`
- `src/game.js`
- `vendor/three.min.js`
- `vendor/GLTFLoader.js`

## Controls

- `WASD` move
- `Shift` sprint
- Left click / Space to shoot
- Right click / Q to aim
- `R` reload
- `E` search/interact
- `1-8` switch weapons
- `Z/X/C/V/B/G` use medical, food, and ammo supplies
